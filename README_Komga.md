# Aidoku → Komga 自动转换器

## GUI 工具箱（新增）

双击 `Start_Komga_Converter.bat`，现在进入 `komga_gui.py` 主窗口，包含书库检查、Aidoku 转换、网站补缺与更新三个分页。

网站补缺分页：为本地漫画目录保存对应的 CopyManga 详情页链接，点击“检查全部更新”比较本地话数和网站目录，确认预览后点击“补齐到最新”。对应关系保存在 `copy_sources.json`。从旧的 `manga_titles.txt` 中交叉核对书名与本地话数，并逐部验证网站目录后，已配置 101 部作品；其他目录需要进一步确认来源。只处理可识别数字话数的正篇，番外等特殊篇章需手工核对。网站最新“试看”会保留在章节名。站点返回空目录、章节数量不一致、错误状态、页面不匹配或下载异常时会停止；不会把反爬产生的空目录当作“已是最新”。

网站目录中的普通话（`type=1`）与单行本卷（`type=2`）分开识别，同编号可以同时保留。卷优先下载并使用三位纯数字目录名：第 5 卷为 `005`、第 10 卷为 `010`；普通话仍使用 `第0005.000话`。只有完整标题为“第X卷”或“X卷”、且卷号为 0–999 的内容才自动视为正式卷；年份、区间、小数、特典和番外等含数字标题不会误转成卷目录。Aidoku CBZ 转换也自动采用这套卷名规范，不能安全转换的标题保留原名而不是令整批任务报错。“规范已有卷名”会先预览，再把精确匹配的 `第X卷` 或不规范纯数字卷目录统一为三位数字；超过三位的纯数字目录会跳过，遇到目标冲突时整批不执行，操作日志保存在 `volume_rename_logs`。后台更新运行时禁止重命名。

网站偶尔会把同一卷同时放在 `default` 和 `tankobon` 分组。只有同卷号恰好存在一个 `tankobon` 候选时才自动选择该单行本版本；普通话重复、多个 `tankobon` 或没有明确单行本候选时仍会停止并显示卷号和分组，防止误选版本。

网站声明的章节数量与实际返回列表不一致时，程序会把它视为临时截断响应，等待后重新读取完整详情页和目录，最多重试两次。GUI 的“检查全部更新”若仍有单部作品失败，会将该行标为错误并继续检查剩余作品；只要存在检查失败项，“补齐到最新”仍保持禁用，避免使用不完整目录。实际写入阶段遇到无法确认的目录仍会停止。

大批量更新：点击“启动/续跑后台更新”，程序只更新 `source_preflight.json` 中已通过来源核对的作品，从缺话较少的漫画开始，单线逐章写入。“网站补缺与更新”页下方会每秒自动刷新本轮作品、章节和当前页进度，无需反复点“查看后台进度”。可点“停止后台更新”；会在当前页后退出，重启时重新检查本地目录，仅补尚缺的章节。HTTP 429/5xx（包括 520）及连接中断会有限次数退避重试，仍失败时冷却后重新下载当前话；不会无限请求。Windows 短暂锁住进度文件时也会重试写入。若网站持续失败、验证页、图片错误或目录冲突，任务会停止并把原因记入 `update_logs/latest_status.json` 和逐章日志；不会绕过网站限制。后台任务可能运行许多小时，期间保持电脑、NAS 和网络可用。其余有同话数多版本或本地话数领先网站的作品不会自动下载。进度数值是本轮运行统计，续跑时会从零重新计数，但已保存章节不会重新下载。

每章先在 `.copy-updating-*` 临时目录下载，逐页转成 PNG 并验证，再一次性提交到漫画目录。`.copy-manga-update.json` 清单记录来源章节 ID、页数与图片哈希。已有同话数的章节目录或 ZIP/CBZ 都视为存在，不覆盖、不替换损坏章节。网络中断后可重新“检查全部更新”继续。本站网页结构若变化，需要先更新解析逻辑。请仅下载有权保存的内容，并遵守网站访问限制。

书库检查选择 `Z:\Manga`：每个直接子目录视作漫画，每个漫画下的直接子目录视作章节。快速检查统计最新数字话数、页数、页码间隙、零字节和转换清单缺页；完整检查额外逐张解码及验证清单哈希。可先快速检查全部，再对选中漫画完整检查。选中漫画可在下方查看逐章问题，支持搜索、停止和导出 JSON 报告。嵌套目录、CBZ/CBR/PDF 会显示未覆盖提示，不能当作已验证。不会连接 Komga API。

“网站核对缺页并清理”是完整检查的联网扩展：只检查 `copy_sources.json` 中已经登记网址的漫画，读取 CopyManga 当前章节图片列表，并与散图目录内的纯数字页名逐页比较。明确缺页的章节会进入一个默认全部不勾选的候选表，详细显示缺少页码；用户必须逐项勾选并再次确认后，才会永久删除该散图目录及其同名 ZIP。无网址、网络/限制页异常、网站目录不完整、版本无法唯一选择、章节对应不明确或本地结构不安全时一律跳过。执行删除前会重新核对目录与 ZIP 快照，变化项拒绝删除；结果记录在 `page_audit_logs`。

GUI 中所有耗时任务使用统一进度区，显示当前漫画/章节/页面、完成数量、百分比、已用时间、预计剩余时间和预计总耗时。尚未统计出总量、等待网站重试或等待人工确认时会显示活动进度与“计算中/等待操作”，不会伪造百分比。预计时间按本次运行的实际速度动态修正；后台更新区也会每秒刷新整批章节的时间估算。

“一键打包章节为 ZIP”只为缺少同名 ZIP 的散图章节新增文件。已有非零 ZIP 直接跳过，不会在每次运行时重新解压、哈希全部旧书，因此前置检查主要只需枚举漫画目录；已有 ZIP 也永不覆盖。0 字节 ZIP 由“清理 0 字节 ZIP”单独处理。

缺号仅是疑似问题。整数正篇从第 1 话开始检查：如果本地最早为第 15 话，会提示疑似缺少第 1–14 话；中间编号间隙也会列出。图片页码同样从 1 开始检查。无法根据本地文件判断最后还应有多少话/页，连续编号也不能证明内容完整。未知章节名、番外和“试看”保留原标签，最新话显示本地最高可识别话数，并不代表网站最新话。完整检查读取 NAS 图片耗时较长。

Windows 启动时启用原生 DPI 感知，并统一使用 Microsoft YaHei UI 10pt；高分屏缩放下表格行高随 DPI 调整。如果窗口已打开，关闭后重新双击启动器才能应用字体设置。

话数排序：选择一部漫画 → “话数排序重命名预览” → 查看结果 → 应用。整数和小数统一为 `第0011.000话`、`第0011.500话`、`第0012.000话`。保留原后缀，未知名称不改，超过三位小数或 9999 话要求手动处理。目标冲突会禁止执行。每次操作在项目 `rename_logs` 内记录原路径、新路径和完成状态；若中断，按日志确认已完成项再恢复，工具不会覆盖或自动回滚。操作仅改目录名，不改图片；尚未在你的正式书库批量执行。

Komga 的 Sort Number 元数据也会控制排序，因此目录重命名不保证已有服务端排序立即改变。应用前保留 Komga 数据库备份，之后重新扫描并检查 Sort Number；不要提前清空回收站。参考：https://komga.org/docs/guides/edit-metadata/ 。

转换分页默认勾选排序兼容命名；已有同话数且相同后缀的唯一目录会沿用原路径，以免重复生成。CLI 添加 `--sortable` 可启用；取消勾选可生成旧命名。

双击 `Start_Komga_Converter.bat`，选择输入目录和输出目录，点击“扫描预览”，检查中文漫画名和章节名后点击“开始自动转换”。默认输出到 `Z:\Manga`。

当前下载目录实际是 `Z:\未命名文件夹\Downloads\zh.copymanga`。可以选择 Downloads、zh.copymanga 或单部漫画的目录；会递归查找 CBZ/ZIP。

生成结构：`漫画名\第01话\001.png`。图片会按原文件名中的数字排序，使用 Pillow 解码后写为真正的 PNG（不是改扩展名）。PNG 通常比 WebP 大，请留出空间。ComicInfo.xml 的 Series 和 Title 优先；缺失时访问配置网站的章节页，读取 h4.header。网络超时/验证页/缺失标题会记录失败并继续其他章节。保留“试看”、番外等标记。

源文件不会移动或删除。每章在临时目录完成后才提交到目标目录。重复导入通过源文件和所有输出 PNG 的 SHA-256 校验跳过。已有章节但无法确认一致时报告冲突，绝不覆盖。失败/中止章节清理自己的临时目录；突然断电可能留下 `.converting-*` 临时目录，勿当作完成章节。停止后已完成章节保留，下次可继续。

转换结束在输出根目录生成 `conversion-report-*.json`。本工具只生成图片目录，不会修改 Komga 账户、数据库或触发扫描；按现有 Komga 书库配置扫描即可。新漫画是否位于现有书库扫描范围内取决于你的书库根目录设置。

如现有漫画目录名称与元数据不同，可建立 JSON 名称映射，在界面中选择，例如：

```json
{
  "xianggelilafulongtiyashizuolierenxiangshenzuofaqit": "你现有的漫画目录名"
}
```

键支持漫画 slug 或原始中文漫画名；值为输出目录名。不会模糊匹配或自动改动已有目录。

依赖：Python 3.11+（含 Tkinter）、Pillow、pycryptodome。安装：`python -m pip install -r requirements-komga.txt`。

命令行仅预览：
```powershell
python aidoku_to_komga.py --input 'Z:\未命名文件夹\Downloads\zh.copymanga' --output 'Z:\Manga' --offline
```
增加 `--convert` 执行。默认联网仅用于缺失元数据时；`--offline` 完全禁用联网；`--mapping names.json` 指定名称映射；`--base-url https://www.copy20.com` 设置补全网站。

不支持密码压缩包、多帧图片或无编号且顺序不明的图片语义；无数字时按文件名排序，请确认预览和来源。压缩包上限 8 GiB 解压大小、单图 256 MiB、10000 个条目。原有项目脚本保持原样，新工具不调用原项目中的删除或移动脚本。
